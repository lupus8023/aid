# AID 0.1.200

本版将 Story 和连续剧的新视频统一为每镜一张分镜首帧、一个连续镜头，按动作和完整对白决定时长。导演提示细化站位、走位、运镜触发与镜尾交接；已提交和已完成片段继续复用。

- ComfyUI 普通 H3 生成统一 FL2VA pruned + DaSiWa Bypass + T8 四步，旧设置不会恢复到八步。模型对照改善了抽查中的持续叠影，尚未根治烧录字幕。
- 新剧本不再平均安排镜长或硬凑目标总秒数；ComfyUI 实测请求2秒得到56帧，未拉长至5/15秒。旧剧本需要重新生成才能重新规划镜长；视觉一键重做继续保留原稿。
- 《杯喜》类道具修稿失败后改为逐字原文证据复核，并保存恢复策略。真实旧稿一次修复通过，仅去掉第9/10镜多挂的白玉杯ID，未改对白或动作。
- 新网页检查 Companion 0.1.200 的生成能力，防止新前端与旧本地生成逻辑混用。
