# AID 0.1.201

本版修正 H3 基础模型与加速 LoRA 的匹配，并将官方 h3-prompt-writing 的结构与镜头调度规则融入图生视频、Story 和连续剧公共生成逻辑。

- 统一使用已核验的 DaSiWa REF2VA Hybrid pruned 权重与其专用 T8 四步 LoRA，保留4步、video/audio shift 12/3、Bypass。该加速 LoRA 仅适配指定 checkpoint，替代0.1.200中的错误配对。
- 提示词依据单图及参考素材采用相应字段结构，保留真实道具名称、逐字对白和音色分工；导演明确运镜方向、幅度、停止条件，以及手与道具的接触和支撑关系，减少重复动作与空间矛盾。
- 原生对白改用声音承载逐字台词的画面约束。两条同图、同种子、同参数对照的抽样未再出现旧烧录字幕；这不代表所有输入均已根治。
- Story和连续剧在提交视频前检查导演稿是否有效；网页制作和Director入口要求新版Companion，避免使用旧模型配对。已有付费片段仍按兼容规则复用。

验证：641项回归测试、TypeScript、网页和Companion构建通过。最终代码的《杯喜》第1集复测完成前7镜，第8镜已提交后因云端SSH中断暂停，第9–16镜未提交，完整成片验收尚未完成。恢复信息及任务号已保存，恢复连接后继续原任务。
