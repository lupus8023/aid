## 实跑发现的 Director / T8 兼容故障

普通视频 `MiniMaxH3AudioConditioningT8` 报核心引用布局改变，但实际 ComfyUI 核心未升级。根因是长视频 Director 永久替换 `MiniMaxH3.extra_conds` 和 `PackedLayout.__init__`，任务结束未还原，触发 T8 的未知实现保护。

- `cloud/patches/h3_context_patches.aid.py` 增加整段 Director 计划的作用域清理；`director-scope-executor.patch` 将其包住 `execute_director_plan_core`。成功/异常均还原自己拥有的原函数，不拆除第三方补丁、不关闭 T8 保护。
- 仅更新生产 GPU Director 的这两个文件，原文件备份 `/root/ComfyUI/aid_node_backups/aid-20260905-director-scope/`。模型、LoRA、采样步数/算法、音频参数未变。确认队列为空后重启 ComfyUI。
- `scripts/test-director-patch-scope.py` 在真实 GPU 环境用 CPU 模式验证：复现污染、成功/异常/再次使用后恢复同一核心函数、T8 保护仍有效。不加载权重、不生成收费素材。
- 真实连续剧两集共 32 段视频及两份成片均完成，验证普通短视频链路恢复。本次未重新跑 60 秒长视频视觉验收。
