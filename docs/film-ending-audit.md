# 整片末镜的无配音区间

首集真实测试发现，仅在 H3 提示词写“最后一秒没有台词”并不足够：6.584 秒的视频里，最后一句到 6.24 秒才结束。不能截断对白、整体静音、加黑帧或冻结画面来冒充达标。

只给整片最后一个视频段增加两秒生成余量，其他段的时长规则不变。v0.1.190 起，末尾留白由 H3 生成提示词约束，Story 和连续剧自动成片不再下载末段做额外 Fish ASR，也不等待其结果或依据识别结果重生成视频。转写服务连接失败、缺少时间戳和旧核验未通过均不再成为自动交付门槛。

历史测试中，延长到 9.417 秒仍只留下约 0.54 秒；延长到 12.25 秒反而重复台词。这说明仅增加时长不是可靠的纠错办法。用户对一秒结尾的要求是“做不到不勉强”：现在保留原片，在分镜卡和本版本成片列表提示已跳过额外核验，不宣称已核验通过，也不会静音、截词、加黑帧或冻结画面冒充达标。

旧任务卡在末镜核验时，更新后点击“从断点重试”即可复用已完成且输入未改变的视频继续合成。原任务 ID、源 URL、缓存键、生成签名、历史核验与旧修复记录原样保留；不删除诊断，也不改成通过。图片、声音、逐字台词和动作均不变。导出前恢复所有应有视频片段及检查媒体完整性的保护仍保留。

既有 `audit-video-ending` 接口仅保留为显式诊断入口，自动生产不调用；诊断仍按视频内容 SHA-256、预期台词和规则版本缓存，不记录 API 密钥。预览、前端提交和后端请求的时长规则未改，避免更新使已付费视频签名失效。

回归见 `tests/film-ending-audit.test.mjs`、`tests/film-ending.test.mjs`、`tests/video-pacing.test.mjs`。覆盖无核验结果、旧核验失败或成功、过期核验、旧修复记录和多镜末段；断言仅增加提示、付费素材与签名不变、断点仍识别为完成、生产页面不再请求 ASR。历史诊断证据保留于 `outputs/gpt-season-remake-20260901/ep1-ending-gate-real-check.json`，不是新版本的交付门槛。
