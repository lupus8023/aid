# 整片末镜的无配音区间

首集真实测试发现，仅在 H3 提示词写“最后一秒没有台词”并不足够：6.584 秒的视频里，最后一句到 6.24 秒才结束。不能截断对白、整体静音、加黑帧或冻结画面来冒充达标。

现在只给整片最后一个视频段增加两秒生成余量，其他段的时长规则不变。自动 ComfyUI 生产在合成前对末段现有视频做 Fish ASR，检查完整台词的转写匹配及最后发声时间；末尾需留至少一秒并加 0.1 秒时间戳余量。转写只是自动检查，不代表已人工试听或语音识别完全准确。

实际测试中，延长到 9.417 秒仍只留下约 0.54 秒；延长到 12.25 秒反而重复台词。这证明仅增加时长不是可靠的纠错办法。用户对一秒结尾的要求是“做不到不勉强”：台词匹配、仅留白不足时，保留原片并在分镜卡和本版本成片列表显示明确警告，不继续购买重生成，也不把核验结果改成通过。不会静音、截词、加黑帧或冻结画面冒充达标。

只有台词转写明显不匹配时才执行最多两次末段内容修复。次数、原任务 ID、源 URL 和本地缓存键写入断点历史；图片、前面的所有视频、人物声音和逐字台词不变。新的付费任务仍按原流程立即保存回执，断线后查询同一个任务。服务连接失败或时间戳缺失只重试核验，不清除视频或花费生成预算。达到模型上限或内容修复次数上限后保留全部素材并报告台词核验未完成。

核验按视频内容 SHA-256、预期台词和规则版本缓存，不记录 API 密钥。预览、前端提交和后端请求采用同一个时长规则，避免展示有留白、实际仍提交旧时长。

回归见 `tests/film-ending-audit.test.mjs`、`tests/film-ending.test.mjs`、`tests/video-pacing.test.mjs`。真实首集旧末段被新接口判定不通过的证据在 `outputs/gpt-season-remake-20260901/ep1-ending-gate-real-check.json`；最终是否达标以重跑结果和成片末秒检查为准。
