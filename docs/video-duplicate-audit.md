# 视频生成后的角色重复检查

第二集第1镜的参考图只有 Luna 和 Rill，但生成视频在横移的约 3.5 秒处，左右两边短暂同时出现 Luna 的身体。图片核验无法覆盖视频生成之后产生的问题。

ComfyUI 自动单镜流程在完成视频后，分别检查视频 20%、50%、80% 的三个采样帧。每个视觉请求只含一张视频帧：实测把参考图和三张帧放进同一个请求，会混淆参考画面和被检查画面，漏掉明确存在的副本。每帧独立列出可见头部的位置和身份，程序统计同一画面中的副本，不能把同一个角色出现在不同帧误算成重复。单独的手、手臂、衣物或卷轴不能计为额外人物。在明确没有匿名背景人物的场景里，也检查超过已声明角色数的额外头部；描述中的画外人群不算画内群众。允许背景人物的场景不应用这个数量限制，包括剧本明确写出的侍从、群众、士兵、鲨鱼队列等无台词背景角色。判断上下文同时读取画面描述和导演的相机、动作、收尾说明，避免遗漏只写在运镜说明里的背景群众。

任何可疑帧都触发附近 ±0.12 秒的进一步检查，中间已检查的帧直接复用结果。相邻帧复查仍有至少两个帧存在明确证据才重生成该片段，最多两次；任务编号、缓存键、生成指纹与检查证据保留在断点历史，图片、逐字台词和其他片段不变。纠错提示要求同一个角色保持单一身体，不能在运镜中复制或叠化成另一个版本。完整提示词的人工编辑也不能丢掉这条已确认的纠错方向。

服务不可用、拒绝核验、证据不确定都不等于通过，也不据此购买新视频；会在分镜和成片列表保留需复核提示。采样不是全片逐帧审查，可能漏掉未采到的短暂变形；不宣称能够保证零缺陷。此检查不判断美感、CG程度、自然裁切或人物应否始终露出全身。

多镜共用一段的片段暂不自动做此检查，因为各镜允许的人员数量、背景和入画时机不同；不能套用单镜封闭角色数量规则。测试见 `tests/video-duplicate-audit.test.mjs`。
